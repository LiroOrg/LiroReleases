## Возможности

| Раздел | Что есть |
| --- | --- |
| **Рисование** | кисть, фигуры, линии, стрелки, связи между объектами, текст, стикеры |
| **Картинки** | вставка из файла, из буфера и по ссылке, замена по месту, предпросмотр |
| **3D-фигуры** | куб, пирамида, призма, цилиндр, конус, шар: вращение, перенос, заливка граней |
| **Графики** | координатная плоскость с сеткой и осями, кривые по формуле |
| **Объекты** | слои, выравнивание, привязка, блокировка, поиск по тексту, отмена действий |
| **Библиотека** | доски в папках, значки и цвета, поиск, перенос библиотеки целиком |
| **Файлы** | приём доски из буфера или из файла, просмотр картинок, PDF и видео |
| **Экспорт** | PNG, PDF, автономный HTML, ZIP со всеми картинками, JSON |

## Установка

Скачайте **`Liro-1.0.0-x64-setup.exe`** из [релизов](https://github.com/LiroOrg/LiroApp/releases) и запустите.

Установщик на русском языке: мастер, выбор папки, ярлык на рабочем столе,
удаление через «Программы и компоненты».
